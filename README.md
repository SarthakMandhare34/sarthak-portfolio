# Sarthak Mandhare — Developer Portfolio

My personal portfolio website, built with React 19, TypeScript, and Vite. It presents my projects, technical skills, and professional experience.

## Tech Stack

- **React 19**
- **TypeScript 5.7**
- **Vite 6**
- **CSS**
- **Framer Motion 11**

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/SarthakMandhare34/sarthak-portfolio.git
   ```

2. **Navigate to the repository directory**

   ```bash
   cd sarthak-portfolio
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

Open the local URL displayed in your terminal to view the portfolio.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm test` | Run automated tests |
| `npm run build` | Build the project for production |
| `npm run preview` | Preview the production build locally |
