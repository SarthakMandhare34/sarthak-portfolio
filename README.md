## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- [NPM](https://www.npmjs.com/) (bundled with Node.js)

### Installation & Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SarthakMandhare34/sarthak-portfolio.git
   cd sarthak-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   Compiles optimized production assets into the `dist/` directory.

5. **Preview production build:**
   ```bash
   npm run preview
   ```
